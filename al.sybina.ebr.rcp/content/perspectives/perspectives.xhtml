Capcode perspectives

Capcode is organised in perspectives for example, you can have a perspective 'Configuration', to organise all the views necessary to configure your capcode installation, a perspective "Navigation" to display the charts and all other views needed for navigation:


navigation perspective

configuration perspective

The perspectives are a means to organise views by thema.
A perspective defines the initial set and layout of views in the main window.
Perspectives define visible action sets, which you can change to customize a perspective.
You can save a perspective that you build in this manner, making your own custom perspective that you can open again later.
Depending on the configuration (adding plugins to the initial set of Capcode functions) may define supplementary perspectives. For example, the plugin weather comes with its own perspective, so does the A.I.S plugin, etc.

How to change perspective?



1) by selecting the menu "Perspectives", then selecting the desired perspective from the menu.
2) pressing directly the combination of keys proposed in the Perspectives menu (eg F4 for weather).
3) Ctrl+Shift+P Shows a dialog listing all the available perspectives
4) Ctrl+Shift+F8 for the previous available perspective
5) Ctrl+F8 for the next available perspective
