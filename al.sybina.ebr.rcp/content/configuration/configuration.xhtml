Configuration of your intrumentation

1) Introduction

There are different ways to define the instrumentation of your capcode software.
Capcode receive messages from your instruments via serial communication ports
To select the serial communication port that will be used:

1) automatically

select the scan button , all available serial communication ports should appear as follow:

2) manually

select the add comm port button , and enter the characteristics of the port, usually the default values are ok. For AIS, set the baud rate to 38400, or the one specified in the technical leaflet of your instrument.
You can also select the menu "add comm port":

When you connect your instruments, the ports that receive data are marked with a green dot:
You can double click on the port to see the instruments connected. If you double click on an instrument and see the NMEA messages running on this port.

Select now the freeze button, to select only the comm ports having NMEA messages (it will release the other ports)

Finish by pressing the validate button, to validate and store this configuration for further starts of capcode.
