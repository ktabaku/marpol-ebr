How to create a route

There are several means to create a route in capcode:
  • Directly on the chart
  • by selecting waypoints from the waypoints view
  • by importing a route from another tool or gps device (as capcode uses gpx format)

1) Open the Routes and Waypoints perspective

2) From the menu "Routes" select "create new route"

3) add route directly on the chart:

Ctrl+mouse click on the chart where you want to add the point. The point will be added just after the last selected route point. It will become automatically the new selected point so a new Ctrl+Click will add points in sequence

3 bis) add route with existing waypoint from the database

Drag a waypoint from the waypoints view and drop it the route view at the position where you want to add the route. (It will be inserted before the point on which the drop is done)

4)Import a route from another program

As capcode use the gpx format to store waypoints, routes and tracks, it is very easy to transfer data from a software or a device using also gpx. We recommend the excellent GpsBabel for that purpose. Capcode will come soon with an interface to GpsBabel. Before that, you just have to load the file with the menu "Route/Open Route", and load any route produced in gpx format

To change the position of a route point easily, just select it with the mouse on the chart's view and drag it to the next position. Please note that today, there is no "undo" function.
